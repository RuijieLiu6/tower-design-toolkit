## 1. What we are building

An **open-source, web-first platform** where Vancouver Tall Challenge entrants, and later any Vancouver tall-building designer, take a tower from massing to competition boards **without leaving the tool**:

1. **Basic mode:** model or import massing (.3dm, OBJ, IFC; Revit via IFC; SketchUp via OBJ) and tag programs. This is **Layer 0**.
2. **Evaluation nodes** read Layer 0 and return a metric, a good/bad judgement with **the source of every threshold**, and a visual.
3. **Advanced mode:** structure, MEP, vertical transportation, code, facade and materials, interior and activity programme.
4. **Present mode:** style, camera presets, AI renders from **your own viewport**, drawings, and four A2 boards checked against the VTC rules.

Every module is a **categorized node** on a Grasshopper-like canvas. Users switch nodes on and off, run all or step in, and the community uploads, comments on and forks nodes.
