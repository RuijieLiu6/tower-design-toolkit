- Findings: {'BLOCKER': 2, 'MAJOR': 12, 'MINOR': 9}
- Verdict: The packet is well researched and honest about its gaps: library choices, licences and most sources check out, and the npm versions were confirmed. It should not pass yet. The biggest risk is not technical. Defaults are public (giscus requires a public repository, forks are public, templates get shared), and that can breach VTC terms 4.1, 5.1 and 5.3 for the very entrants the tool serves. The sandbox protects computation but not module-supplied visualizations. The worker-CSP design does not match how sandboxed-iframe workers inherit CSP, and GitHub Pages cannot send the headers it needs. Several statuses overclaim: INP is labelled verified, a keyboard alternative is treated as meeting WCAG 2.5.7, and npm provenance is cited for files that are not npm packages. SemVer 0.x, units and true north, and the schedule relative to the 30 Nov deadline need fixing.
